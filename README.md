# Kolunya Zone | UX/UI Designer Portfolio

A modern, dark-themed personal portfolio website for **Kolunya Zone (Ozone)**, a UX/UI Designer based in Thailand.

## 🚀 Features

- **Modern Aesthetic:** Clean, dark-themed design focused on visual impact.
- **Responsive Layout:** Fully responsive grid and flexbox-based layout.
- **Typography:** Uses **JetBrains Mono** for a technical yet approachable feel.
- **Theme Toggle:** Switch between dark and light modes seamlessly.
- **Project Showcase:** A structured grid to display design projects.

## 🛠️ Built With

- **HTML5:** Semantic structure for better accessibility and SEO.
- **Vanilla CSS:** Custom styles with CSS Variables for theme management.
- **JavaScript:** Lightweight script for theme toggling and interactive elements.
- **Google Fonts:** Integration of JetBrains Mono.

## 📂 Project Structure

```text
/
├── portfolio/
│   ├── index.html    # Main entry point
│   ├── style.css     # Styles and theme variables
│   └── script.js    # Theme toggle logic
├── plan/
│   └── our_plan.md   # Project development roadmap
└── README.md         # Project documentation
```

## 🌐 Deployment

This project is designed to be deployed via **GitHub Pages**.

1. Push the code to your GitHub repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch and the root directory.
4. Click **Save**.
